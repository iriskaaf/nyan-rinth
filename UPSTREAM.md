# Upstream

NyanRinth 1.0.7 is based on [AstralRinth](https://github.com/42WASD/AstralRinth), beta commit `69e9ef400c5c77b0360d87bffabb952fa5aa6e76`, itself derived from [Modrinth](https://github.com/modrinth/code).

This snapshot was imported from the preserved `NyanRinth-1.0.7-source.zip` archive. The author date records the archive file timestamp; the commit date records the GitHub import. This is a release snapshot, not a reconstruction of individual development commits.

Local editor settings, agent configuration, temporary reports and environment overrides are excluded. Original copyright notices and package licenses are retained. Bundled authlib-injector 1.2.8 is unmodified; its [source](https://github.com/yushijinhun/authlib-injector/tree/v1.2.8) is available under AGPL-3.0.
