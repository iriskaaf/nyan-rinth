NyanRinth основан на лаунчере Modrinth. В нём доступны вход Ely.by, каталог и коллекции скинов, локальная синхронизация игровых параметров и собственные акцентные цвета. Ранние выпуски использовали AstralRinth; текущая серия Beta перенесена непосредственно на официальную основу Modrinth.

**Текущая Beta: [0.2.0-beta.1](https://github.com/iriskaaf/nyan-rinth/releases/latest)** · [Все выпуски и архивы](https://github.com/iriskaaf/nyan-rinth/releases)

## Возможности

| | Что доступно |
| --- | --- |
| **Аккаунты Ely.by** | Вход с поддержкой 2FA, обновление сессии и запуск игры через встроенный authlib-injector. Поддерживаются офлайн-аккаунты. |
| **Скины внутри лаунчера** | Каталог Ely.by, поиск по тегам, предпросмотр Steve и Alex, применение скинов и сохранённые коллекции. |
| **Моды и модпаки** | Каталог Modrinth и отдельные сборки Minecraft со своими загрузчиками, модами и сохранениями. |
| **Импорт** | Файлы `.mrpack` и сборки поддерживаемых лаунчеров, включая Prism, PineconeMC, Modrinth и AstralRinth. |
| **Общие игровые настройки** | Выбор параметров для локальной синхронизации между сборками. Запись в `options.txt` работающей игры откладывается до её закрытия. |
| **Оформление и память** | Акцентный цвет, настройки оперативной памяти и отдельная страница аккаунтов. |
| **Диагностика** | ZIP с журналами и сводкой состояния. Известные секреты фильтруются, исходная БД аккаунтов не включается. |

## Установка

Откройте **[Releases](https://github.com/iriskaaf/nyan-rinth/releases)** и выберите выпуск. Текущая серия `0.2.0-beta.*` имеет статус Beta. Версия `1.1.0` — последний архивный выпуск на AstralRinth; она также имеет статус Alpha.

- `NyanRinth_<версия>_x64-setup.exe` — установщик Windows.
- `NyanRinth_<версия>_x64.exe` — приложение без установки. Оно использует обычную папку данных NyanRinth и не является изолированной portable-версией.
- `SHA256SUMS.txt` — контрольные суммы файлов.
- `Source code` — исходники соответствующего тега.

Нужны Windows x64 и Microsoft Edge WebView2 Runtime. Бинарники не подписаны коммерческим сертификатом издателя. Начиная с 0.2.0-beta.1 лаунчер автоматически скачивает подписанные обновления из GitHub Releases. Для перехода с Alpha нужно один раз установить Beta вручную.

После установки добавьте Ely.by или офлайн-аккаунт, создайте или импортируйте сборку и запустите игру. Для каталога и коллекций откройте раздел «Скины» и подключите управление скинами.

Аккаунт Ely.by не заменяет Microsoft-аккаунт на серверах, которые требуют его. Для отображения скинов у других игроков нужна поддержка Ely.by на клиенте или сервере. После смены скина может потребоваться перезапуск Minecraft и обновление кеша сервиса.

## Переход со старой версии

Сделайте резервную копию `%APPDATA%\dev.nyanrinth.launcher` и собственных папок сборок. При переходе с версии, выпущенной раньше `1.1.0`, сначала обновитесь до `1.1.0`.

Новая платформа переносит данные в отдельную БД и сохраняет исходную. Игровые файлы могут оставаться общими у старой и новой версии: запуск прежнего EXE не откатывает их изменения. Подробнее — [в заметках о переходе](docs/MIGRATION.md).

## Статус Alpha

Готовые сборки публикуются для Windows x64. Выпуски macOS и Linux здесь не предоставляются.

- Реальная загрузка PNG в Ely.by остаётся известной проблемой.
- Полная проверка входа, 2FA, обновления сессий и всех загрузчиков на новой основе ещё не завершена.
- Миграция проверялась на синтетических профилях; переход основного пользовательского профиля и установка поверх старой версии требуют дополнительных проверок.
- Управление скинами зависит от веб-API Ely.by и может потребовать обновления при изменении сайта.

Об ошибках сообщайте в [Issues](https://github.com/iriskaaf/nyan-rinth/issues/new/choose): укажите версии лаунчера, Minecraft и загрузчика, а также шаги воспроизведения. Перед публикацией диагностики просмотрите её: журналы могут содержать личные адреса серверов и пути.
